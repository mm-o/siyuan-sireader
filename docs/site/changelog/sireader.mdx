## v2.8.5 (2026-11-26)

### 修复

- 修复 PDF 重排只能读到第一屏、继续翻页就报 `merge: Failed to execute 'postMessage' on 'Worker': An ArrayBuffer is detached and could not be cloned` 的问题：累积的重排 PDF 交给阅读器时会被转移给 pdfium 线程，主线程那一份随即失效，续排再拿它拼接必然失败。现在自己保留一份可用的累积结果，交给引擎的是拷贝。
- 修复续排拼进来的页是空白、并伴随 `non-page object in page tree` 的问题：跨文档搬页改用 MuPDF 的 `graftPage`（`insertPage` 只接受 PDFObject）。
- 修复向前续排把新窗口压在已有内容上、导致同一页出现两次的问题：续排窗口现在接在已有区间外面，页序不重叠。
- 修复续排后界面跳到新窗口开头的问题：按累积前的位置换算页码，续排完仍停在同一处正文。
- 修复重排临时文件无限累积：重排 PDF 改为只在内存里生成，不再写入 `data/public`；只有点击「导出重排 PDF」时才落盘到 `assets/`，并且包含当前窗口里新画的标注。历史遗留的重排临时文件可以直接删除。
- 重排里复制或发送到笔记的标注与回链，现在指向原始 PDF 的对应页（重排页自动换算回源页），不再写入打不开的临时重排地址。
- 修复显示失败时按钮仍显示“已进入重排”，以及退出重排后源 PDF 仍沿用重排标注键的问题。

### 优化

- 重排窗口从 12 页缩到 6 页，距边界 2 页即开始续排，首屏和翻页都更快；同一会话不再重复搬运、解析整本 PDF，分窗合并在 Worker 内增量插页，合并结果也不再重新压缩（只喂给阅读器，不落盘）。
- 重排的标注与阅读进度改用内容哈希作为键，不再依赖临时文件是否存在。

## v2.8.4 (2026-11-26)

### 新增

- PDF 主题适配：纸张、画布、正文、页面阴影和控件圆角都跟随阅读主题，预设主题和自定义主题色都能适配，切换主题即时生效，不用重新打开 PDF。
- 设置新增「运行时组件」一节：PDF 重排运行时（MuPDF）、语音运行时（sherpa-onnx）和离线语音模型集中一处，每行显示是否已下载、保存目录和下载按钮。

### 优化

- 「笔记插入」按用途拆成「笔记插入」与「标注与同步」两组，设置行统一为标题在上、控件占满一行，说明收进悬停提示。
- PDF「页面清晰度（扫描件）」从「笔记插入」移到「界面布局」，说明精简为一句话。
- 同步链路只保留建块、更新、追加评论、删除四个动作，去掉无效的内容指纹去重和全部调试日志。
- PDF 主题的换算收在一个文件里，删掉主题名清单、深浅探测和逐节点上色。

### 修复

- 标注同步真正按「插入位置」执行：打开文档、Daily Note、剪贴板各走各的，绑定文档只在「笔记本下 / 文档下」和插入失败时兜底。
- 剪贴板目标会真的复制内容，每标注一次。
- 标注块格式不再变形：一条标注一个块，更新时整块重写，评论并入笔记，不再多套一层引述块。
- 光标插入失败时退回绑定文档并提示；「添加时同步」不再重复插入。
- 删除标注只删它自己的块，不再残留或报 `tree not found`。
- 绑定文档探活走文件系统，刚创建的绑定文档不再被误判为已删除。
- 链接模板按设置原样导出：空占位符不再留下 `****`、悬挂的 `- ` 或多余空行，其余 Markdown 照抄。
- 多行笔记、多条评论不再掉出引用块；`$&`、`$1` 也不再被当成替换语法吃掉。
- 文档绑定不再需要会员：没有「书籍编辑」权益时，菜单里的「绑定文档」直接可用。
- 扫描版 PDF 重排不再输出空白：带文字层的 OCR 版 PDF 直接用文字层重排，一页都排不出来时直接报错说明原因。
- 重排与离线朗读的运行时下载修复：补齐下载源，失败提示直接给出下载地址和保存路径。

## v2.8.3 (2026-11-23)

### 修复

- 启动更快：思阅的侧栏与顶栏图标不再比其它插件晚出现，数据检查改到后台进行，不挡界面；阅读器仍会等检查完成，老用户升级后不会看到空书架。
- 启动不再重复检查数据：已经迁移过的旧数据会记住，之后启动直接跳过；书架没有变化时也不再逐本重新核对记录，启动更省资源、更快。
- PDF 标注同步到文档不再重复插入：以前给标注加评论、标记完成、取消完成、修改标注或反复编辑评论时，文档里会多出重复的标注块；现在一条标注始终只对应一个块，评论按顺序接在标注后面。
- 删除 PDF 标注会真正删掉文档里的块：以前删除后块会立刻被重新插回来，还可能弹出 `tree not found` 报错。
- 修改标注不再清空已追加的评论：标注块是引用块、正文在其子块中，以前改写整块会连子块里的评论一起重建。
- 修改评论不再多出一条：每条评论会记住自己的块，之后修改只改那一行。
- 标记完成 / 取消完成只改变状态，不再往文档里补写文字。
- 用顶部「注释」画的高亮、下划线，同步到文档时会带上选中的原文；以前只有回链和「标注」两个字。
- 截图类标注带文字注释时，链接模板的「文本」位置显示选中原文，注释只进「笔记」，两者不再互相顶掉。

### 优化

- 安装体积减半：PDF 重排引擎（MuPDF）与离线朗读的语音引擎不再随插件打包，改为首次使用时自动下载，安装体积从约 50 MB 降到约 20 MB；首次使用「PDF 重排」或「离线朗读」时各下载一次，之后本地缓存、可离线使用。
- 清理历史构建残留文件（约 3.3 MB）以及不再需要的运行时文件，插件目录更干净。
- PDF 文本框输入中文不再显示方块：阅读器内部的字体链统一换成带中文字形的一套。
- 注释侧栏的回复框改为多行输入框：可拖拽调整高度，长批注不再挤在单行里；回车换行，`Ctrl/Cmd + Enter` 提交。
- 点击右侧注释面板跳转时不再有额外的滚动动画，与阅读器其它跳转行为保持一致。
- 精简标注同步实现：去掉无效的内容指纹去重、重复定义的插入函数以及整套排障日志，同步链路只保留建块、更新、追加评论、删除四个动作。

## v2.8.2 (2026-11-19)

### 新增

- 书架搜索改为全库检索：在任意分组里搜索都不再只搜组内，分组名、书内书名、作者、标签、文件名与路径、状态、格式、元数据（出版社 / ISBN / 简介等）全部纳入匹配；空格分词、全部命中即显示，命中的分组本身也会作为结果出现，紧凑视图里分组内的命中书不再被折叠隐藏。
- 书架网格封面状态改为“压边水印”样式：在读 / 读完 / 未读 压在右下角并随封面自适应，倾斜 + 模糊光晕做出毛绒质感，不再像贴片徽标那样错位。

## v2.8.0 (2026-11-17)

### 新增

- EPUB 等非 PDF 阅读器新增全屏按钮：进入/退出全屏一个按钮，图标随状态切换（PDF 仍用阅读器自带全屏）。
- 翻译窗口加宽到 720px（最大 92vw），原文/译文自适应内容并可上下拖动，底部「翻译引擎」和「加入标注」固定不随滚动，弹窗外层不再出现滚动条。
- 新增「页面清晰度（扫描件）」设置：五档可调，默认跟随官方默认值。高精度扫描件在常用缩放下容易发虚，调大后更清晰，代价是内存占用上升；切换后重新打开 PDF 生效。

### 修复

- 修复付款后点「恢复授权权益」需要重启思源才能用会员功能的问题：授权状态改为全应用共享，恢复后立即生效。
- 修复书架在分组内搜索只能搜到组内内容的问题：现在有关键词就搜全库，并把分组名、作者、状态、标签、文件名与路径一并纳入匹配（空格分词，全部命中）。
- 修复形状标注导出的图片模糊：导出改用约 288dpi 的高清出图，小标注也保证足够像素，并补上多边形标注的导出。
- 修复从文档里点开标注回链时停在“上次阅读位置”而不是目标页：跳转目标改为先入单槽队列、阅读器就绪后消费，并取消“恢复上次位置”，未打开/已打开/跨书三种情况都能定位（去掉原来的定时轮询重试）。
- 修复设置项悬停时底部冒出横向滚动条（灰条）：设置列表只允许纵向滚动，并把「笔记插入」那一组的行结构统一成其它组的扁平结构。

## v2.7.3 (2026-11-17)

### 修复

- 思盘（siyuan-cloud）云盘书籍读取增加路由回退：`/d/` 下载路由失败时自动改用 `/p/` 预览路由重取，避免直链跳转丢掉认证后拿回错误页、导致 EPUB 报 `File type not supported`。
- 上游返回 gzip 压缩体但响应头缺少 `Content-Encoding` 时，按魔数自动解压后再交给阅读器，解决「文件是完整的、却被当成不支持的格式」的问题（`.gz` 文件本身除外）。
- 取到的内容不是真正的 EPUB/PDF 时，错误信息直接给出字节数与文件头内容，便于判断是文件本身还是读取链路的问题。
- 修复同名不同格式的书（例如同一本书的 EPUB 与 PDF）被当成同一本、点击只切换标签而不新开的问题：已打开标签的判定从「标题」改为「书籍 url」，标题只用于显示；老标签页没有记录 url 时仍按标题回退，不会重复开同一本书。
- 修复同一本书重复打开标签页：已打开标签的查找改为覆盖所有布局（右侧、底部），并对 url 做候选归一化比较，同一文件的不同编码地址也能识别。

## v2.7.2 (2026-11-17)

### 新增

- PDF 标注支持绑定思源块并在标注浮条一键「打开块」：导入、添加时同步、发送到文档都会把生成的块记到标注上，手动把 `siyuan://blocks/<id>` 或裸块 id 填进标注链接也会自动转成绑定。
- 书架搜索支持空格分词：`广东 2026` 会要求每个词都命中，并把文件名、路径和链接纳入搜索范围。

### 修复

- 修复 PDF 标注创建后侧栏不显示引用的选中文字：3.x 引擎不再把选区文字写进注解，改为创建时补写 `custom.text`，侧栏、复制回链和发送到文档都能读到引用文字。
- 修复从侧栏点击标注跳转时报 `Cannot read properties of undefined (reading 'x')`：标注矩形同时兼容 `{origin,size}` 与 `{x,y,width,height}` 两种形状，标注图片裁剪与记录写入一并归一。
- 修复形状标注在标注侧栏显示成通用「注释」的问题：现在显示「形状标注」，与文本标注区分。
- 修复 PDF 书签跳转会把缩放比例改掉的问题：书签只有占位矩形，现在只滚到对应页、保持当前比例。
- 修复设置项没有说明文字时，悬停会弹出空白提示条的问题。
- 修复书架「打开数据所在位置」对网盘或已移走的书只提示不支持：现在能解析到本地就定位，找不到就打开链接或提示并复制路径。
- 修复书架右键菜单点空白处后再右键打不开、以及右键出现拖动光标的问题。
- 修复文档里的标注回链在 PDF 已打开但尚未就绪时点击无反应：现在会等文档挂载后重试再定位到标注。
- 修复 PDF 原件缺失时提示不带路径：现在错误信息会带上缺失的文件路径，便于放回文件后继续用同一条回链。
