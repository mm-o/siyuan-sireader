## v2.7.2 (2026-11-17)

### 新增

- PDF 标注支持绑定思源块并在标注浮条一键「打开块」：导入、添加时同步、发送到文档都会把生成的块记到标注上，手动把 `siyuan://blocks/<id>` 或裸块 id 填进标注链接也会自动转成绑定。

### 修复

- 修复 PDF 标注创建后侧栏不显示引用的选中文字：3.x 引擎不再把选区文字写进注解，改为创建时补写 `custom.text`，侧栏、复制回链和发送到文档都能读到引用文字。
- 修复从侧栏点击标注跳转时报 `Cannot read properties of undefined (reading 'x')`：标注矩形同时兼容 `{origin,size}` 与 `{x,y,width,height}` 两种形状，标注图片裁剪与记录写入一并归一。
- 修复形状标注在标注侧栏显示成通用「注释」的问题：现在显示「形状标注」，与文本标注区分。
- 修复 PDF 书签跳转会把缩放比例改掉的问题：书签只有占位矩形，现在只滚到对应页、保持当前比例。
- 修复设置项没有说明文字时，悬停会弹出空白提示条的问题。
- 修复书架「打开数据所在位置」对网盘或已移走的书只提示不支持：现在能解析到本地就定位，找不到就打开链接或提示并复制路径。
- 修复书架右键菜单点空白处后再右键打不开、以及右键出现拖动光标的问题。
- 修复文档里的标注回链在 PDF 已打开但尚未就绪时点击无反应：现在会等文档挂载后重试再定位到标注。
- 修复 PDF 原件缺失时提示不带路径：现在错误信息会带上缺失的文件路径，便于放回文件后继续用同一条回链。

### 修复

- 修复 PDF 标注删除后没有同步删除文档中已绑定块的问题：同一次会话内绑定块信息只写进元数据，删除时却用了创建时的旧快照。
- 修复 PDF 回链首次点击只打开书籍、不跳转标注的问题：阅读器还没就绪时先暂存定位目标，就绪后再执行。
- 修复 PDF 标注定位不准：改为选中标注并把标注区域滚到视口偏上位置，不再只翻到页首导致内容落在下三分之一。
- 修复锁屏／休眠回来后 PDF 阅读进度跳回封面：恢复页会被首次布局覆盖，现在会补跳一次，并在恢复期间不写入进度。
- 修复形状标注插入文档后不显示标注框（框内其他标注也随之不可见）：新增「标注图片包含标注样式」开关，打开后导出的图片带标注框。
- 修复 PDF 评论和标注笔记输入框打不出中文：输入法组合期间的回车不再被上游当成提交。
- 修复形状标注「添加时同步」不生效：工具样式默认值以响应式对象传给引擎 worker，触发 DataCloneError，标注事件因此不回流。
- 修复书架「打开数据所在位置」对链接／外部导入书籍提示“没有本地文件”：现在按链接打开或定位到 `file://` 原文件。
- 修复 PDF 工具栏「删除遮盖」命令用了不存在的图标名，控制台反复告警。
- 修复打开 PDF 后思源刷新／重载卡住：上游默认开启「离开前确认」，文档只要被判定有未保存改动就会拦截 `beforeunload`，而标注由思阅自己持久化、引擎里始终是“未保存”，刷新因此被拦住；现已关闭该确认。
- 给插件卸载流程的保存与等待加上限：某个写入卡住时不再让思源的刷新／重载一直挂着。
- 修复 PDF 批注「删除」按钮提示混入英文快捷键名的问题。
- 修复形状标注导出的图片带标注描边，现在只截取页面内容。
- 修复「绘制后保持工具」开关不生效：关闭后绘制完成会回到默认工具；该开关同时出现在「注释」和「形状」工具栏，状态会保存。
- 修复大尺寸扫描页在部分缩放下发虚：底图预算 `render.fullPage.maxWidth` 由 640 提高到 1280。
- 修复滚到页尾会带动外层页面滚动：关闭上游新增、默认开启的 `stage.scrollChaining`。
- 修复思盘（siyuan-cloud）网盘里的 PDF 报 `is not an asset path` 无法打开：插件虚拟路径不再交给思源内置 PDF 标签页，统一回落插件阅读器。
- 点击思盘文件时优先使用思盘新增的 `data-reader-href`（`siyuan://plugins/siyuan-cloud/open?path=…`），与文档内插入、复制的链接同源。
- 文档排除路径规则对 `data-reader-href` 形态的思盘链接同样生效。

### 已知问题

- **部分老 PDF 里的中文整段不显示**：这类文件多在 2000 年代由方正、WPS 等排版软件导出，正文用的是国标字库，文件里既没有嵌入中文字体，也没有字符映射表。打开后英文、数字和版式都正常，只有中文是空白，不是文件损坏，也不是导入方式的问题。目前阅读引擎还不能为这种缺字文件自动补字形，只能等上游修复；插件侧已试过并验证两条可行路线都不可用（引擎自带的 CJK 回退字体会让渲染直接报内存越界，PDFium 原生的系统字体接口在这个 wasm 构建里不生效、回调从未触发），因此本版不带临时字体、也不打产物补丁，避免把 8 MB 字体和补丁白塞进安装包。在此期间这类文件请先用其他能内嵌字体的阅读器打开，或用 OCR／重新导出带字体的 PDF。上游修复后思阅会跟进；扫描版、表单、签名和普通 PDF 不受影响。

### 修复

- 修复旧版批注工具设置触发 PDF 白屏或思源卡死的问题。加载旧设置时转换为当前支持的颜色、线宽、虚线和箭头样式。
- 保留旧批注数据兼容，转换几何、颜色、箭头端点和印章资源；新批注通过 EmbedPDF 原生事件写回思阅记录。修复空颜色批注导致侧栏批注列表无法显示的问题。
- 修复 PDF 翻译沿用旧选区 API、矩形快捷键和遮盖删除快捷键失效的问题，并更新翻译、词典、复制回链和笔记本图标。
- 修复打开 PDF 标签时来源不是有效文件对象导致阅读器无法挂载的问题。
- 修复设置面板多行输入框被固定最小高度撑高的问题。移除 `min-height:96px` 后，文本框高度重新由 `rows` 决定：文档链接排除的关键词、路径、正则恢复为 2 行，不再显示成 4 行高。
- 国标 PDF 中文乱码仍未解决。已确认 3.1.0 的官方 `engine.fallbackFonts` 在未嵌入中文字体的 Adobe-GB1 样本上导致 WASM 渲染内存越界，因此没有启用；上游有 CJK 缺字和字体配置讨论，尚无与该崩溃吻合的修复。
- 修复从 v0.9.x～v1.2.x 升级后旧版 SQLite 数据不再被读取、书架显示为空的问题。启动时自动识别插件目录里的 `reader.db` / `reader.last-good.db`，以及老版本迁移后留下的 `petal/siyuan-sireader-backup/<时间戳>/` 备份，导入书目、标注、分组、设置和阅读记录；按「数据源 + 文件字节数」幂等，重复启动或重复拷贝同一份库不会重复导入。
- 修复旧笔记里 `pdf://标题_大小` 形式的回链在书籍被重新导入为 `file://` 条目后点击提示「书籍不存在」的问题。打开书籍、续读链接、标注面板和链接悬停预览统一按「文件名」与「标题 + 大小」解析到现有书目，命中后跳转到原标注位置。

### 优化

- 优化文档链接排除设置：改为直接填写的关键词与路径输入框，常用路径一键勾选添加，并提供链接实时测试命中结果；正则保留为高级选项。
- 调整文档链接排除设置项位置，收纳到「打开与界面 → 书架配置」下方，与书架相关选项集中，避免在笔记插入中查找。
- 调整侧边栏顶部导航顺序：笔记本按钮移到标注之后，设置按钮固定为最后一项；同时修正老配置补齐笔记按钮时可能把它追加到设置之后的问题。
- 从 EmbedPDF 2.x Snippet 迁移到官方 `@embedpdf/viewer` 和 `@embedpdf/engine` 3.1.0 API，移除旧 Snippet、重复的文档管理、滚动和缩放代码，以及依赖 Shadow DOM 的 DOM 补丁。
- 阅读器命令与快捷键映射到 EmbedPDF 原生 `commands`；文档生命周期使用 `viewer.documents.open()`、`setActive()`、`download()` 和 `close()`。额外标签与思阅书架批注数据隔离。
- 页面导航、倍率、滚动和旋转交由原生 `stage`；缩放快捷键使用原生倍率步进，减少自定义滚动及缩放逻辑。移除重复的 PDF 滚动方向设置。
- 批注改用原生 `annotation.create()`、`update()`、`delete()` 和事件；视图上下文通过 `viewer.get()`、`viewer.forDocument(id).get()` 获取。思阅继续保存兼容的旧批注记录。
- 封面和离线批注预览复用 `localEngine().open()`、`page.text.get()` 与 `page.render.image()`，移除隐藏 Viewer 和旧引擎桥接。
- 重排生成的 PDF 通过原生多文档接口在同一 Viewer 中打开，继续保留源页与批注映射及切换前的保存等待。
- 构建使用本地 Viewer、Engine Worker 和 WASM，调整重排 Worker 的浏览器构建处理，消除构建警告。
- 旧数据迁移改为合并语义：书架里已有的书、已有标注（按标注 ID 去重）、进度和设置一律优先，只补缺不覆盖；`daily_reading` 标注汇总进 `daily.json`，PDF 阅读进度与章节在为空时回填，旧库原件不被删除或改写。
- 旧标注兼容增强：PDF 的旧式扁平标注（highlight / note / ink / shape）在打开时按真实页高转换为 EmbedPDF 结构，页码、矩形、墨迹路径与便签内容保持原样，标注 ID 不变，重复打开不会产生重复标注。
- 旧库解析引擎按需加载：只在检测到旧版数据库时才下载内联 WASM 的 SQLite 解析器，不增加启动开销与主包体积。
