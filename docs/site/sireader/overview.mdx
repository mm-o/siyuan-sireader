## 思阅是什么

在思源里管理电子书、阅读 EPUB/PDF/TXT，并把标注带着回链写回文档。书籍、进度和标注保存在思源工作空间；会员只决定功能开放，不搬运书籍文件。

## 功能地图

- 书架：9 种格式导入、复制或链接导入、分组标签评分、批量操作与数据补全
- 阅读：6 个导航模块、单页与双页与连续滚动、目录搜索书签脚注、CFI 定位
- 设置：界面、主题、字体、排版、进度、视觉增强、朗读参数
- 标注：7 色 4 样式、快速标注、标签与行级备注、回链与自动同步
- PDF：工具栏、二十余种批注工具、表单印章签名、遮盖、重排、测量大纲缩略图、多文档标签、只读
- 工具：在线与离线词典、8 个翻译引擎、系统与在线与离线朗读、快捷键
- 效率：速记与笔记本、阅读统计、在线书源、微信读书
- 数据：目录结构、备份、隐私边界、集成 API

## 边界与限制

- 需要思源 3.6.5 或更新版本。
- 桌面、移动端与伺服环境的文件访问能力不同，本机路径不会自动变成其他设备可访问的文件。
- 闪卡、牌组与 FSRS 不属于本插件。
