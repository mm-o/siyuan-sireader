## 支持的文件与来源

导入选择器接受 EPUB、PDF、MOBI、AZW3、AZW、FB2、CBZ 和 TXT。不同格式由不同解析器处理，接受扩展名不代表所有变体都能解析；加密、损坏或需要平台解密的文件不能按普通电子书处理。

“添加内容”包含本地文件、链接和云盘入口。链接每行一个地址，能否打开取决于该设备与来源服务的访问权限。

## 复制导入还是链接导入

- 复制导入：文件进入思阅托管目录，便于统一管理；跨设备需要随思源工作空间同步或迁移。
- 链接导入：只记录来源地址；移动文件、改盘符、链接过期或退出账号都会让条目打不开。

桌面本机路径在手机、浏览器或 Docker 中通常不可直接用。跨设备续读优先用可同步的托管文件、思源附件或各设备都能访问的稳定云盘路径。

## 批量导入

一次选择多个文件，等预览解析完成，勾选后统一填写标签、分组、状态和评分，再确认导入并核对成功与失败数量。大文件解析期间不要重复点击。

## 移除与彻底删除

- 移除：移走书架条目并清理该书的托管文件与封面，保留阅读数据与标注。
- 彻底删除：同时删除阅读数据与标注，不能当作隐藏操作。

托管清理不会删除原始外部文件、远程链接或思源附件，但托管的书籍副本可能被清掉；需要保留原文件时先备份。

## 复制书籍链接

书籍菜单的「复制链接」复制 Markdown 链接（`[三体](sireader://resume?url=…)`），模板与复制、导出标注共用设置里的「链接格式」。粘进文档后点击按阅读进度续读，不带标注定位。

## 数据在哪里

- 结构化数据（书架索引、设置、进度、标注）：`data/storage/petal/siyuan-sireader`
- 托管书籍、字体、背景、词典：`data/public/siyuan-sireader`
