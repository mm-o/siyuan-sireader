## 在线书源

打开在线搜书与来源管理，按来源要求填写地址与认证信息并启用，再输入书名或作者搜索。结果可阅读、加入书架，或在来源提供文件时下载。

搜书是月付会员能力，网络请求经思源内核代理。

在线书架条目可能只有链接：跨设备使用仍需目标设备能访问该来源，必要时重新登录。

## 连接微信读书

1. 打开思阅的“微信读书”入口。
2. 填入自己的微信读书 Agent API Key，测试连接并保存。
3. 同步加载书架、笔记与统计，或在搜索页按关键词查书。
4. 在书籍详情选择阅读或加入思阅书架。

Agent API Key 不是会员绑定二维码，也不要填思源账号密码。连接失败先核对 Key 与来源服务可达性，不要把个人 Key 贴到公开问题里。

## 导入笔记到思源

1. 在“设置 → 笔记插入”选好目标笔记本或父文档。
2. 按需修改“微信读书导出模板”。
3. 对单本执行导入，或从书架批量导入。
4. 核对新建子文档、章节与笔记内容后再重复导入。

模板支持的占位符包括：书名、封面、作者、阅读链接、详情链接、ISBN、出版社、分类、出版时间、字数、阅读人数、评分、简介、目录、划线、书签、想法。

重复导入按稳定书籍 ID 更新同步块；手写笔记请放在同步内容之外并保留备份。

## 边界与限制

- 微信读书只返回平台书籍数据与阅读链接，不提供通用 EPUB/PDF 下载；加入书架不代表已下载文件。
- 连接成功不代表账号拥有每本书的阅读权限。
