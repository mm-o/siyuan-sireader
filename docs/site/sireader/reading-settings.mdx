## 先理解“覆盖开关”

字号、字重、字距、行距、段距、缩进、对齐都各自带一个覆盖开关。只有打开对应开关，阅读器设置才会替换书内样式；关闭时保留电子书自带排版。PDF 与固定版式 EPUB 不参与这套重排。

## 排版

| 分组 | 可调项 |
| --- | --- |
| 文本 | 字体、字号、字重、字距、对齐 |
| 段落 | 行距、段距、首行缩进 |
| 布局 | 四边距、列间距、页眉页脚高度、内容最大宽度 |
| 进度 | 进度样式、参考页数、剩余时间、时钟、电量、24 小时制 |

逐项取值见 [阅读设置参考](/docs/sireader/settings-reference/)。

## 主题与字体

- 内置多套预设主题，也可自定义文字色、背景色与背景图；自定义主题属于体验会员能力。
- 字体可选择本机字体，或导入 TTF、OTF、WOFF、WOFF2 文件。本机字体只对当前设备有效，跨设备请一并带上字体文件。
- 字体、背景与词典支持导入、导出和删除。

## 视觉增强

亮度、对比度、复古色调、饱和度与反色可以叠加，适合夜间或低对比屏幕。这些只影响显示，不修改书籍文件。

## 边界与限制

- 预览面板用于快速确认效果，最终呈现以阅读器为准。
- 扫描版 PDF 没有文字层，调排版不会让它变成可选字的文本。
