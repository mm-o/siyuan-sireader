## 打开入口

启用插件后，从思源右侧栏打开思阅书架；顶部思阅按钮进入设置面板。微信读书是独立入口，可在设置中控制顶部按钮是否显示。

## 第一步：导入一本

1. 在书架选择“添加内容”，先用一本完整的 EPUB 或 PDF 测试。
2. 在预览列表确认书名，勾选要加入的书籍。
3. 选择复制导入或链接导入，区别见 [书架与导入](/docs/sireader/bookshelf/)。
4. 等待解析完成后点击书籍打开阅读器。

## 第二步：读进去

- 目录、搜索、进度条都可以定位；EPUB 支持按百分比跳转，PDF 按页码。
- EPUB 可在阅读设置切换单页、双页、连续滚动，并调整翻页效果与边距。
- PDF 是固定版式，用缩放、旋转和适合页面，不走 EPUB 的段落重排。

## 第三步：留下一条标注

选中文本创建普通标注，写下笔记再回跳验证。标注样式、颜色和标签见 [标注与标签](/docs/sireader/annotations/)。

## 第四步：验证保存

正常关闭阅读器，再从同一书架条目打开，确认进度与标注都在。多设备使用前，先在一台设备完成这一步。

## 边界与限制

- 打开书籍不等于写入思源文档；标注要进入文档需要绑定文档并开启同步，见 [回链与笔记同步](/docs/sireader/link-and-sync/)。
- 只在小程序绑定账号不会传输书籍、进度或标注。
