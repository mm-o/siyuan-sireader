## 绑定与恢复

在“设置 → 会员订阅”确认当前思源账号，点击扫码入口，用微信小程序“思源插件助手”完成绑定或恢复，然后同步权益并核对类型与到期时间。

换设备后仍使用同一思源账号；二维码有有效期，失效后重新生成。

购买后权益没变化时，先在小程序检查绑定账号，再在插件里点恢复，不要重复购买来测试。

## 缓存与离线

- 插件会缓存仍然有效的会员，并定期刷新。
- 短暂请求失败与服务端确认失效的处理不同：缓存不会把已确认失效的权益重新变成有效，也不承诺无限期离线使用。
- 遇到错误先保存完整提示，检查网络与当前思源账号，再重试恢复。

## 权益范围

各等级能开哪些功能见 [会员权益对照](/docs/sireader/membership-matrix/)；购买步骤见 [购买会员](/docs/getting-started/membership-purchase/)。

## 边界与限制

- 会员只决定功能开放，不上传书籍、标注或进度。
- 账号绑定与标注同步是两件事，重新扫码不会找回缺失的书籍文件。
