## 在线查词

阅读器选中词语后打开词典面板。设置中的“词典翻译”可管理在线词典并拖动排序，查询优先返回排在前面的来源。有道与必应属于基础词典（免费），其他高级词典需要体验会员以上。

某一个来源不可用时先切换另一个，不必重装插件。

## 离线词典

在“设置 → 词典工具 → 离线词典”用多文件上传或文件夹导入：

| 格式 | 必需文件 | 可选 |
| --- | --- | --- |
| StarDict | 同名 `.idx` + `.dict.dz`（或 `.dz`） | `.ifo`、`.syn` |
| dictd | 同名 `.index` + `.dict.dz`（或 `.dz`） | — |

普通未压缩 `.dict` 不能满足完整导入条件；只上传 `.ifo` 也得不到可用词典。同一套文件要一次选齐，多套按文件名与相对文件夹分组。

词典资源位于 `data/public/siyuan-sireader/dictionaries`，配置是同目录下的 `config.json`，换设备时两者都要保留。

## 翻译

选中文字后可打开翻译面板，或在设置中启用“划词自动翻译”。可配置默认引擎：Google、微软、腾讯、有道、火山、微信、MyMemory 与 AI。第三方服务的可用性与是否免费由其自身决定。

PDF 翻译结果可以添加为批注，保留选区与译文；结果用于辅助阅读，需要时回原文核对。

## 朗读

朗读入口在阅读器工具栏与思源状态栏。参数、语音来源与离线模型见 [朗读与语音模型](/docs/sireader/tts/)。
