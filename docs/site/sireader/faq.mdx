## 书籍打不开或阅读器空白

先用另一份完整 EPUB 或 PDF 测试。只有一本失败时检查文件是否完整、加密或扩展名被改；全部失败时更新插件与思源后正常重启。详见 [书架与导入](/docs/sireader/bookshelf/)。

## PDF 不能选字、查词或朗读

多半是扫描版只有图片层。用已知可选字的 PDF 对比确认；扫描件需要外部 OCR，插件不做自动 OCR。详见 [PDF 阅读与工具栏](/docs/sireader/pdf-read/)。

## PDF 里的中文不显示或整段缺失

先用一份正常 PDF 对比：如果只有这一个文件的中文是空白，而英文、数字和版式都正常，多半是文件没有嵌入中文字体、也没有字符映射表（2000 年代方正、WPS 排版的老文件常见），既不是文件损坏，也不是导入方式问题。这类缺字只能等阅读引擎上游修复：插件侧已确认现有两种补字方案都会让渲染异常，所以暂时没有可用的开关，上游修复后思阅会跟进。临时办法：用其他能内嵌字体的阅读器打开，或先 OCR／重新导出带字体的 PDF。详见 [PDF 阅读与工具栏](/docs/sireader/pdf-read/)。

## 改了字号却没变化

EPUB 需要打开对应的排版覆盖开关；PDF 与固定版式 EPUB 不重排，应改用缩放。详见 [阅读设置](/docs/sireader/reading-settings/)。

## 换设备后书籍或标注不见了

按顺序检查：思源工作空间同步是否完成、两端是否同一书架条目、托管文件或原链接是否可访问。扫码只同步权益，不带文件。详见 [数据、备份与隐私](/docs/sireader/data-and-privacy/)。

## 思源文档里没有出现标注

检查书籍是否绑定目标文档、“添加时同步”是否开启、目标文档是否可访问。详见 [回链、笔记插入与同步](/docs/sireader/link-and-sync/)。

## 离线词典导入失败

同一套文件要同名并一次选齐；StarDict 需要 `.idx` 与 dictzip 数据，dictd 需要 `.index` 与 dictzip 数据。详见 [词典、翻译与朗读](/docs/sireader/tools/)。

## 朗读没声音或断续

分别测试系统、在线与离线语音，确认权限、音量、模型资源与网络。详见 [朗读与语音模型](/docs/sireader/tts/)。

## 微信读书导入不完整

先测 Agent API Key，再确认账号有对应书籍与笔记，最后检查目标笔记本。该服务不提供 EPUB/PDF 下载。详见 [在线书源与微信读书](/docs/sireader/online/)。

## 会员权益没生效

先在小程序核对绑定账号，再在插件里恢复权益；不要重复购买验证。详见 [会员与账号](/docs/sireader/features-and-access/) 与 [会员问题排查](/docs/troubleshooting/membership/)。

## 怎么反馈问题

导出诊断日志，说明思源与插件版本、系统、文件格式、导入方式与复现步骤，并隐藏 Key、账号与私人内容。详见 [数据、备份与隐私](/docs/sireader/data-and-privacy/)。

## 安装失败

见 [安装问题排查](/docs/troubleshooting/installation/)。
