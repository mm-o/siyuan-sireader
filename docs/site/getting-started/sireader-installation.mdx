## 安装

1. 在思源笔记的插件集市搜索“思阅”。
2. 安装并启用插件。
3. 按提示重新加载，确认插件列表中状态为已启用。

## 首次验证

从思源右侧栏打开书架，导入一本 EPUB 或 PDF，翻页后关闭再打开，确认进度恢复。完整流程见 [第一次阅读](/docs/sireader/usage/)。

## 升级

升级前先保存阅读进度与标注并关闭阅读窗口。升级后先打开一本已有书籍，确认进度与标注仍在再批量使用。

需要思源 3.6.5 或更新版本；思源版本过低时插件无法启用。

## 卸载

在插件面板卸载时，思阅会清理托管文件与插件数据（含 `config.json`、`stats.json`）。原始外部文件、远程链接与思源附件不会被删除。

需要保留阅读数据时，卸载前按下文备份。详见 [数据、备份与隐私](/docs/sireader/data-and-privacy/)。

## 保存与换设备

导入后保留原始文件；跨设备阅读需要思源数据同步带上插件数据与托管文件。只在小程序绑定账号不会传输书籍、标注或进度。
