# 离线词典使用说明 / Offline Dictionary Guide

SiReader 支持导入本地 StarDict 与 dictd 词典。导入后的词典文件会保存到：

SiReader supports local StarDict and dictd dictionaries. Imported files are stored under:

```text
/public/siyuan-sireader/dictionaries/
```

配置文件保存为：

The dictionary configuration is saved as:

```text
/public/siyuan-sireader/dictionaries/config.json
```

旧版本曾使用过的 storage 路径不再读取。请通过新的导入入口重新导入词典。

The old storage path used by earlier versions is no longer read. Please re-import dictionaries through the new import entry.

## 支持格式 / Supported Formats

### StarDict

必需文件 / Required files:

- `.idx`
- `.dict.dz` 或 `.dz`

可选文件 / Optional files:

- `.ifo`
- `.syn`

推荐完整组合 / Recommended complete set:

```text
dictionary.ifo
dictionary.idx
dictionary.dict.dz
dictionary.syn
```

### dictd

必需文件 / Required files:

- `.index`
- `.dict.dz` 或 `.dz`

推荐完整组合 / Recommended complete set:

```text
dictionary.index
dictionary.dict.dz
```

> 注意：当前运行时读取的是 dictzip 压缩数据文件，即 `.dict.dz` 或 `.dz`。普通未压缩 `.dict` 文件不会作为完整词典导入条件。
>
> Note: the current runtime reads dictzip-compressed data files, namely `.dict.dz` or `.dz`. Plain uncompressed `.dict` files do not make a complete importable dictionary by themselves.

## 导入方式 / Import Methods

打开设置中的“词典工具”，展开“离线词典”。

Open **Dictionary Tools** in settings, then expand **Offline Dictionary**.

- 问号图标：打开本说明文档。
- 上传图标：选择多个词典文件。
- 文件夹图标：选择一个词典文件夹。

- Help icon: open this guide.
- Upload icon: choose multiple dictionary files.
- Folder icon: choose a dictionary folder.

### 多文件导入 / Multiple File Import

一次选择同一词典的相关文件，例如：

Select all files belonging to one dictionary at once, for example:

```text
Oxford.ifo
Oxford.idx
Oxford.dict.dz
Oxford.syn
```

也可以一次选择多套词典文件。SiReader 会按文件名自动分组。

You may select files for several dictionaries at once. SiReader groups them by file name automatically.

### 文件夹导入 / Folder Import

推荐把每本词典放在独立文件夹中：

It is recommended to keep each dictionary in its own folder:

```text
My Dictionaries/
  Oxford/
    Oxford.ifo
    Oxford.idx
    Oxford.dict.dz
  Webster/
    Webster.index
    Webster.dict.dz
```

选择 `My Dictionaries` 文件夹后，SiReader 会按相对文件夹和文件基名分组导入，因此同一文件夹中也可以包含多套词典。

After selecting `My Dictionaries`, SiReader groups imports by relative folder and file base name, so one folder may contain several dictionaries.

## 使用逻辑 / Query Behavior

1. 只有启用的离线词典会参与查询。
2. 多个离线词典按设置页中的顺序查询。
3. 找到结果后优先返回第一个可用结果。
4. 拖拽词典条目可以调整优先级。

1. Only enabled offline dictionaries are queried.
2. Multiple offline dictionaries are queried in settings order.
3. The first available result is returned.
4. Drag dictionary rows to change priority.

## 常见问题 / FAQ

### 导入后没有出现词典 / Dictionary does not appear after import

请确认文件组合完整：

Check that the file set is complete:

- StarDict: `.idx` + `.dict.dz` 或 `.dz`
- dictd: `.index` + `.dict.dz` 或 `.dz`

- StarDict: `.idx` + `.dict.dz` or `.dz`
- dictd: `.index` + `.dict.dz` or `.dz`

### 查询时报错 / Query fails

常见原因：

Common causes:

- 数据文件不是 dictzip 格式。
- 文件名匹配错误，导致索引和数据文件不属于同一词典。
- 词典文件本身损坏。
- 当前浏览器环境不支持原生 `DecompressionStream`。

- The data file is not in dictzip format.
- File names do not match, so index and data files are grouped incorrectly.
- The dictionary files are corrupted.
- The current browser environment does not support native `DecompressionStream`.

### 为什么导入到 public / Why public storage?

`/public/siyuan-sireader/dictionaries/` 与书籍文件的托管方式一致，便于通过 SiYuan 文件 API 或公开路径读取，也更方便迁移和备份。

`/public/siyuan-sireader/dictionaries/` follows the same managed-storage model as book files. It can be read through SiYuan file APIs or public paths and is easier to migrate or back up.

## 后续计划 / Roadmap

- 计划支持 MDict 的 `.mdx` 词典及配套 `.mdd` 资源文件。
- 当前使用的 Readest/Foliate 词典模块仅原生支持 StarDict 和 dictd，尚不能直接解析或导入 MDX/MDD。
- 后续将在具备合适的浏览器端解析方案后接入现有词典管理，并处理词条跳转、图片、样式、音频及大词典按需读取。在此之前，可使用 PyGlossary 转换为 StarDict 或 dictd。

- Planned: support MDict `.mdx` dictionaries and companion `.mdd` resource files.
- The current Readest/Foliate dictionary module only supports StarDict and dictd natively, so MDX/MDD files cannot yet be parsed or imported directly.
- Once a suitable browser-side parser is available, it will be integrated with the existing dictionary manager, including entry redirects, images, styles, audio, and on-demand access for large dictionaries. Until then, use PyGlossary to convert files to StarDict or dictd.
