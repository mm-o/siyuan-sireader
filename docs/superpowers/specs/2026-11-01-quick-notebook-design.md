# 思阅快捷笔记本设计

## 目标

为思阅增加一个可从插件侧栏和阅读器中快速访问的笔记本。用户可以将已有思源文档加入个人列表、创建分组，并在小窗或侧栏中查看和编辑文档。设计参考思播笔记本的入口与操作方式。

## 交互

- 思阅插件侧栏增加“笔记”导航项，默认启用；旧版自定义导航配置会补入此项，之后仍可按思阅既有方式调整侧栏项目。
- EPUB 阅读器和 PDF 阅读器各增加笔记本图标按钮。点击后打开统一的可调整大小的小窗。没有上次状态时显示按最近访问排序的文档列表；再次打开恢复上次访问的文档或列表位置。
- 笔记列表包含默认分组和用户创建的分组。新增菜单提供“搜索文档”和“创建分组”。搜索使用思源文档搜索 API；选择结果后加入当前分组。重复添加不改变列表。删除自定义分组时，保留其中的文档并移至默认分组。
- 点击列表文档后，在当前面板中用 Protyle 查看和编辑；返回按钮回到分组列表。文档上下文菜单提供“在思源中打开”“移至分组”和“从列表移除”。移除只删除笔记本中的引用，不删除原文档。
- 小窗和侧栏共享一个 Vue 界面及同一份数据。现有“快捷笔记”热键仍按原逻辑打开目标文档浮窗，避免更改用户已配置的操作。

## 结构与数据

- 新增共享的笔记本组件，既可挂载到 `SettingsDock` 的导航页，也可挂载到 `App.vue` 管理的 SiYuan `Dialog`。
- `App.vue` 负责唯一的小窗生命周期与全局打开事件；阅读器按钮只发送打开事件，避免阅读器销毁时误关闭小窗。
- 通过现有 `src/core/storage.ts` 数据接口保存独立的 `quick-notes.json`。数据只包含 schema 版本、分组、文档引用（思源文档 ID、名称/路径快照、分组 ID、最近访问时间）和上次打开的文档 ID；文档正文始终由思源管理。
- 搜索结果需将思源返回的路径映射为真实文档 ID，并过滤无效结果。加入时校验 ID、去重；分组与文档引用可从上下文菜单移除。
- 旧侧栏设置在读取时合并新增导航项，不覆盖用户现有项目的顺序、启用状态和配置。

分组是扁平列表，不支持嵌套。文档移入不同分组不改变它在思源中的位置。

## 失败处理与验证

- 搜索失败、文档已删除、分组名为空、重复添加和存储读写失败分别给出简洁提示；空列表显示搜索/添加入口。已删除文档打开失败时提示用户将其从列表移除。
- 关闭小窗或卸载视图时销毁 Protyle 并移除事件监听；重新打开时重新读取数据，保证侧栏和小窗之间看到最新列表。
- 实现完成后执行 `pnpm build`，并手动检查侧栏入口、EPUB/PDF 工具栏按钮、搜索添加、分组创建、文档编辑/返回、移除引用和小窗开关。此次不新增或运行测试。

## 范围外

- 不复制思源文档内容到插件存储。
- 不改变现有快捷笔记热键或标注/笔记插入流程。
- 不增加文档删除、跨分组树形嵌套、拖拽排序或媒体关联等能力。
