# EPUB 阅读器页脚设计

日期：2026-10-08

## 目标

让 SiReader 的 EPUB 阅读页眉页脚在位置和信息分区上接近 Readest：页眉仍在左上；页脚分为左侧章节剩余时间、中间当前时间与电量、右侧阅读页数。PDF 使用 EmbedPDF，不在本次范围内。

## 现状与参考

SiReader 的 `Reader.vue` 已有页眉和页脚，但页脚把进度与时钟合并成单行并右对齐；设置中已有页脚、进度和当前时间开关，尚无章节剩余时间和电量状态。Readest 将页数进度（例如 `41/539`）与电量状态分开显示，并为剩余时间、时钟、电量及电量百分比提供独立设置。

## 设计

- 保留现有页眉左对齐和页脚显隐行为。页脚使用稳定的三栏布局：剩余时间左对齐、时钟/电量居中、页数进度右对齐；长内容截断，不遮挡阅读交互。
- 为章节剩余时间、电量、电量百分比分别增加布局设置；新设置沿用 Readest 默认值：剩余时间和电量关闭，电量百分比开启。现有进度、时钟及 12/24 小时制偏好不变。
- 剩余时间按当前章节渲染器的剩余页数估算。SiReader 尚无逐页阅读速度数据，因此采用 Readest 无个人速度记录时的回退值：约每页 0.94 分钟；无法取得有效页数时不显示估算。
- 通过浏览器 Battery Status API 读取电量并监听变化；API 不可用或尚无数据时隐藏电量，不引入平台专用依赖。当前时间独立定时刷新，不依赖翻页事件。
- 新增设置文案及剩余时间文案的中英文翻译。

## 验证

- 对剩余页数到分钟数的计算、边界值及进度显示编写单元测试。
- 运行相关测试、项目测试与构建，并检查 `Reader.vue` 的布局检测结果。
- 确认 PDF 阅读器及现有设置默认值/持久化行为未改变。

## 范围边界

不新增逐页速度历史或存储格式，不重做页眉视觉样式，不改变 EmbedPDF 页脚，也不改动既有 i18n/changelog 工作区变更。
